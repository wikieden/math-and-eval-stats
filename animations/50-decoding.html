第 50 章 · 温度、top-p 与投机解码

配套讲义：第 50 章 · 解码与采样：温度、top-k / top-p、beam search、投机解码、约束解码。6 个候选 token 的 logits [2, 1.5, 1, 0, −1, −2]。投机解码：草稿分布 q 是目标 p 和另一个分布 r 按“差距”混合，q = (1 − d)·p + d·r。

看点：① 温度：T 小柱子变尖，T 大变平；② top-p：从最高的柱子开始累加，蓝色是保留并重新归一化的集合，其余变灰；③ 投机解码：深蓝是接受部分 min(p, q)，橙色是重采部分，叠起来始终等于灰框 p；d 越大 α 越小，右上角是 γ = 4 时每次前向期望得到的 token 数。
