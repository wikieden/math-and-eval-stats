附录 · 按目标读：学 VLA、学运动控制的章节索引

写于 2026-11-23。全书 66 章不用从头读到尾。这里按两个目标排好顺序：每一阶段读本书哪几章、学到的数学用在 VLA 讲义 和 运控讲义 的哪一章。
标记：必 = 不读会卡住；选 = 想读懂论文附录 / 推导时再读。已写好的章（1、2、8、9、13、18、24）带链接，其余还是大纲，章名见 目录。
本文缩写：VLA = Vision-Language-Action（视觉 / 语言 / 动作模型）；VLM = Vision-Language Model（视觉 / 语言 / 模型）；BC = Behavior Cloning（行为 / 克隆）；MLE = Maximum Likelihood Estimation（最大 / 似然 / 估计）；KL = Kullback–Leibler divergence（两位统计学家的姓 / 散度）；ELBO = Evidence Lower BOund（证据 / 下界）；GMM = Gaussian Mixture Model（高斯 / 混合 / 模型）；DCT = Discrete Cosine Transform（离散 / 余弦 / 变换）；LoRA = Low-Rank Adaptation（低秩 / 适配）；RTC = Real-Time Chunking（实时 / 分块执行）；PPO = Proximal Policy Optimization（近端 / 策略 / 优化）；GAE = Generalized Advantage Estimation（广义 / 优势 / 估计）；GRPO = Group Relative Policy Optimization（组内 / 相对 / 策略优化）；DPO = Direct Preference Optimization（直接 / 偏好 / 优化）；DAgger = Dataset Aggregation（数据集 / 聚合）；PD = Proportional-Derivative（比例 / 微分控制）；LQR = Linear Quadratic Regulator（线性 / 二次 / 调节器）；LIPM = Linear Inverted Pendulum Model（线性 / 倒立摆 / 模型）；ZMP = Zero Moment Point（零力矩 / 点）；MPC = Model Predictive Control（模型 / 预测 / 控制）；WBC = Whole-Body Control（全身 / 控制）；QP = Quadratic Programming（二次 / 规划）；KKT = Karush–Kuhn–Tucker（约束优化最优条件）；iLQR = iterative LQR；MPPI = Model Predictive Path Integral（模型预测 / 路径积分）；BPTT = BackPropagation Through Time（随时间 / 反向传播）；AMP = Adversarial Motion Priors（对抗 / 运动 / 先验）；ESKF = Error-State Kalman Filter（误差状态 / 卡尔曼滤波）；IMU = Inertial Measurement Unit（惯性 / 测量 / 单元）。
